Comment Crawl

A multi-platform product review crawling pipeline that turns Excel product links into Redis-dispatched Scrapy jobs and normalized review records.

Python Scrapy Scrapy-Redis FastAPI Redis MySQL
6 Platforms
2 Core tables
100 Reviews/page

System flow

From product links to structured reviews

01 Excel Upload

Batch product URLs and SKUs enter through a FastAPI endpoint.

02 URL Parser

Platform and product IDs are detected from each marketplace URL.

03 Product Store

Product metadata is upserted into the all_products table.

04 Redis Queue

Platform-specific request payloads are pushed into spider queues.

05 Scrapy Spiders

GraphQL, REST, and HTML responses are parsed by platform spiders.

06 Review Store

Ratings and comments land in normalized MySQL review tables.

Engineering notes

          
What this demo represents

        

        

          

            
Reusable crawler core

            

              Platform spiders share persistence and rating logic through a base
              spider while keeping request construction and response parsing
              platform-specific.
            

          

          

            
Queue-based execution

            

              Product ingestion is separated from crawling through Redis queues,
              so jobs can be retried, paginated, and consumed by dedicated
              spiders.
            

          

          

            
Schema normalization

            

              Different marketplace review shapes are transformed into shared
              product_reviews fields for downstream analysis.
